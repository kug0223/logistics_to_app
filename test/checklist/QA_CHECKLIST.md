# AlFit 수동 QA 체크리스트

> **용도**: 자동화 테스트(Firestore Rules·Flutter 단위)로 커버하지 못하는 실기기 UI/UE 검증  
> **실행 기기**: Android (최소 Android 10 이상), 실제 기기 권장  
> **기준 빌드**: 출시 전 최종 빌드 (`flutter build apk --release`)  
> **결과 기록**: 각 항목에 ✅ PASS / ❌ FAIL / ⏭ SKIP (해당없음) 표기
