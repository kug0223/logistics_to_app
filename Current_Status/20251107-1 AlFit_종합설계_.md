## 프로젝트 개요

### 목적
AlFit은 물류센터/창고 등의 단기·장기 일자리 매칭 플랫폼입니다.

### 핵심 특징
- ✅ **단기/장기 통합 관리**: 하나의 앱에서 단기 알바와 장기 계약 근무 모두 관리
- ✅ **신뢰성 기반 매칭**: 자동 충돌 방지, 노쇼 관리
- ✅ **출퇴근 관리**: GPS/비콘 기반 출퇴근 체크
- ✅ **프로필/리뷰 시스템**: 검증된 지원자 정보와 근무 이력
- ✅ **양방향 소통**: 지원 시 메시지, 확정/거절 시 관리자 메시지

### 대상 사용자
1. **지원자 (USER)**: 단기/장기 일자리를 찾는 사람
2. **사업장 관리자 (BUSINESS_ADMIN)**: 인력이 필요한 물류센터/창고 관리자
3. **플랫폼 관리자 (SUPER_ADMIN)**: 전체 시스템 운영자

## 핵심 방향 결정사항

### 1. 장기 근무 계약 방식
```
✅ 채택: 계약서 1개 = 전체 기간 (소속 개념)
- 지원 → 확정 → 소속 계약 체결
- 매일 출퇴근 체크
- 월별 정산
```

### 2. 출퇴근 관리
```
✅ 채택: GPS/비콘 + 관리자 수정
- 지원자: GPS/비콘으로 출퇴근 체크
- 관리자: 확인 및 수정 가능
- 지원자가 잘못 찍으면 → 수정 요청 → 관리자 승인
- 사업장별로 GPS/비콘/수동 선택 가능
```

### 3. 충돌 관리
```
✅ 채택: 자동 취소 + 알림
- 확정 시: 겹치는 대기중 지원 자동 취소
- 지원 시: 확정된 시간대 완전 차단
```

### 4. 메인 화면 (지원자)
```
✅ 채택: 혼합형 (C안)
┌─────────────────────┐
│ 🔔 오늘 근무        │
│ 쿠팡 09:00 출근    │
└─────────────────────┘
┌─────────────────────┐
│ 💡 오늘의 추천      │
│ 신세계 14~18       │
└─────────────────────┘
┌─────────────────────┐
│ 📅 이번 주          │
│ [월][화][수][목][금] │
└─────────────────────┘
```

### 5. TO 관리 (관리자)
```
✅ 채택: 통합 관리 + 필터
[TO 관리]
├─ 필터: [전체][단기][장기]
└─ 당일 근무자: 장기+단기 혼합 명단
```

### 6. 급여 정산
```
✅ 채택: 사업장별 설정
- paymentCycle: 'daily' | 'weekly' | 'monthly'
- 사업장마다 다르게 설정
```

### 7. 예상 수입
```
✅ 채택: 확정만 표시 (A안)
💰 이번 달 확정 수입: 1,500,000원
   (대기중 800,000원)
```

### 8. 본인 인증
```
✅ Phase 1: 간단 버전 (이름, 생년월일, 계좌)
🔮 Phase 5+: 휴대폰 인증 API, 계좌 인증 API
```

### 9. 리뷰 시스템
```
✅ Phase 1: 관리자 → 지원자 (단방향)
🔮 Phase 5+: 지원자 → 사업장 (양방향)
```

### 10. 핵심 가치
```
✅ 채택: 균형 (D안)
Phase 1: 신뢰성 (충돌 방지)
Phase 2: 편의성 (출근 체크)
Phase 3: 수익성 (스마트 추천)
```

```dart
/// 지원서 확정 + 충돌하는 지원 자동 취소
Future<void> confirmApplication(String appId, String adminUID) async {
  // 1. 확정할 지원서 조회
  final app = await getApplication(appId);
  
  // 2. 같은 날짜, 시간 겹치는 대기중 지원서 찾기
  final conflictingApps = await findConflictingApplications(
    uid: app.uid,
    workDate: app.workDate,
    startTime: app.startTime,
    endTime: app.endTime,
    excludeId: appId,
    status: 'PENDING',
  );
  
  // 3. 배치로 처리
  final batch = FirebaseFirestore.instance.batch();
  
  // 3-1. 확정 처리
  batch.update(
    _firestore.collection('applications').doc(appId),
    {
      'status': 'CONFIRMED',
      'confirmedAt': FieldValue.serverTimestamp(),
      'confirmedBy': adminUID,
    },
  );
  
  // 3-2. 충돌하는 지원들 자동 취소
  for (var conflictApp in conflictingApps) {
    batch.update(
      _firestore.collection('applications').doc(conflictApp.id),
      {
        'status': 'AUTO_CANCELED',
        'canceledAt': FieldValue.serverTimestamp(),
        'cancelReason': 'SCHEDULE_CONFLICT',
        'conflictingAppId': appId,
        'conflictingBusiness': app.businessName,
        'conflictingTime': '${app.startTime}~${app.endTime}',
      },
    );
  }
  
  await batch.commit();
  
  // 4. 알림 발송
  if (conflictingApps.isNotEmpty) {
    await _sendCancelNotifications(
      userId: app.uid,
      canceledApps: conflictingApps,
      confirmedApp: app,
    );
  }
  
  print('✅ 확정 완료 + ${conflictingApps.length}개 자동 취소');
}

/// 시간이 겹치는 지원서 찾기
Future<List<ApplicationModel>> findConflictingApplications({
  required String uid,
  required DateTime workDate,
  required String startTime,
  required String endTime,
  required String excludeId,
  String status = 'PENDING',
}) async {
  // 1. 같은 날짜의 모든 지원서 조회
  final snapshot = await _firestore
      .collection('applications')
      .where('uid', isEqualTo: uid)
      .where('workDate', isEqualTo: Timestamp.fromDate(workDate))
      .where('status', isEqualTo: status)
      .get();
  
  // 2. 시간대 겹침 필터링
  final conflicts = <ApplicationModel>[];
  
  for (var doc in snapshot.docs) {
    if (doc.id == excludeId) continue;
    
    final app = ApplicationModel.fromFirestore(doc);
    
    if (_hasTimeOverlap(startTime, endTime, app.startTime, app.endTime)) {
      conflicts.add(app);
    }
  }
  
  return conflicts;
}

/// 두 시간대가 겹치는지 체크
bool _hasTimeOverlap(String s1, String e1, String s2, String e2) {
  final start1 = _timeToMinutes(s1);
  final end1 = _timeToMinutes(e1);
  final start2 = _timeToMinutes(s2);
  final end2 = _timeToMinutes(e2);
  
  return !(end1 <= start2 || end2 <= start1);
}

int _timeToMinutes(String time) {
  final parts = time.split(':');
  return int.parse(parts[0]) * 60 + int.parse(parts[1]);
}
```

```dart
double calculateReliabilityScore(UserModel user) {
  double score = 100.0;
  
  // 노쇼: -10점씩
  score -= user.noShowCount * 10;
  
  // 평점: +20점 (만점 기준)
  score += (user.rating / 5.0) * 20;
  
  // 근무 횟수: +5점 (최대 20점)
  score += min(user.totalWorks * 0.5, 20);
  
  // 제재: -30점
  if (user.isSuspended) score -= 30;
  
  return max(0, min(100, score));
}
```

1. 모든 컬렉션 이름은 복수형 (applications, users, businesses)
