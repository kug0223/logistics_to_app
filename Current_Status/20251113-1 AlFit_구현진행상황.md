## 🛠️ 기술 스택

### 프론트엔드
- **Framework**: Flutter 3.24+
- **Language**: Dart 3.0+
- **상태 관리**: Provider
- **UI 라이브러리**:
  - table_calendar 3.1.2 (캘린더)
  - loading_animation_widget (로딩)
  - fluttertoast (알림)

### 백엔드
- **Firebase Authentication**: 사용자 인증
- **Cloud Firestore**: 실시간 데이터베이스
- **Firebase Storage**: 파일 저장 (예정)
- **Firebase Messaging**: 푸시 알림 (예정)

### 외부 API
- **Daum 주소 검색 API**: 주소 입력
- **Kakao Geocoding API**: 좌표 변환
- **url_launcher**: 전화/지도 연동

### 개발 도구
- **IDE**: Android Studio, VSCode
- **버전 관리**: Git
- **테스트**: Flutter Test (예정)
