## 프로젝트 개요

### 🎯 프로젝트 목표
물류센터와 구직자를 효율적으로 연결하는 모바일 매칭 플랫폼 개발

### 👥 사용자 역할
- **SUPER_ADMIN**: 플랫폼 운영자 (전체 관리)
- **BUSINESS_ADMIN**: 사업장 관리자 (TO 생성, 지원자 관리)
- **USER**: 구직자 (TO 검색, 지원, 근무 관리)

### 📱 핵심 기능
1. 역할 기반 인증 시스템
2. 단기/장기 TO 관리
3. 동적 업무 유형 설정
4. 실시간 지원 관리
5. 근무 스케줄 캘린더

#### 구현 내용

- ✅ table_calendar 패키지 통합

- ✅ 날짜 선택 및 포커스

**2. 필터 시스템**
```dart
필터 옵션:
- 전체 보기 (ALL)
- 확정만 보기 (CONFIRMED)
- 대기만 보기 (PENDING)
- 거절만 보기 (REJECTED)
```

**3. 월별 통계 카드**
```dart
표시 정보:
- 확정 근무: X일
- 대기 중: X건
- 예상 수입: XXX,XXX원
```

**4. 일정 상세**
- 날짜별 일정 리스트
- 상태별 자동 정렬
- 사업장 정보 표시
- 시간/업무/급여 정보

**5. 지원 취소 기능**
```dart
대기중 (PENDING):
- 간단한 확인 후 즉시 취소

확정 (CONFIRMED):
- 패널티 경고 표시
- 주의사항 안내
- 확인 후 취소 가능
```

**6. 상세 정보 팝업**
```dart
표시 정보:
- 📍 사업장 정보
  - 사업장명
  - 주소
  - 전화번호 (클릭 시 통화)
  - 센터 안내사항
  
- 💼 업무 정보
  - 업무 유형
  - 근무 시간
  - 급여
  - 근무 기간 (장기)
  - 근무 요일 (장기)
  
- 📋 공고 정보
  - TO 제목
  - 업무 설명
  - 주의사항
```

## 기술 스택 및 아키텍처

### 프론트엔드
- **Framework**: Flutter 3.24+
- **Language**: Dart 3.0+
- **상태 관리**: Provider
- **UI 라이브러리**:
  - table_calendar (캘린더)
  - loading_animation_widget (로딩)
  - fluttertoast (알림)

### 백엔드
- **Firebase Authentication**: 사용자 인증
- **Cloud Firestore**: 실시간 데이터베이스
- **Firebase Messaging**: 푸시 알림 (예정)

### 외부 API
- **Daum 주소 검색 API**: 주소 입력

```dart
}

장점:
- 코드 중복 제거
- 쿼리 단순화
- UI 로직 통일
```

### Issue 2: N+1 쿼리 문제
**문제**: 지원자 10명 로딩 시 11번의 DB 쿼리 발생 (느림)

**해결**:
```dart
// Before: 순차 로딩
for (var app in applications) {
  final user = await getUserById(app.uid);  // 10회 쿼리
}

// After: 병렬 로딩
final futures = applications.map((app) => 
  getUserById(app.uid)
).toList();
final users = await Future.wait(futures);  // 1회에 모두 처리

결과: 5초 → 0.5초 (10배 향상)
```

### Issue 3: 시간 충돌 감지
**문제**: 동일 시간대 중복 지원 방지 로직 복잡

**해결**:
```dart
bool hasTimeOverlap(Application a, Application b) {
  // 날짜 확인
  if (!isSameDay(a.workDate, b.workDate)) return false;
  
  // 시간 파싱
  final aStart = parseTime(a.startTime);
  final aEnd = parseTime(a.endTime);
  final bStart = parseTime(b.startTime);
  final bEnd = parseTime(b.endTime);
  
  // 겹침 확인
  return aStart.isBefore(bEnd) && bStart.isBefore(aEnd);
}
```

### Issue 4: CustomScrollView 레이아웃 깨짐
**문제**: 캘린더 높이가 동적으로 변하면서 하단 레이아웃 깨짐

**해결**:
```dart
// Column + Expanded 방식 (X)
Column(
  children: [
    Calendar(),  // 높이 가변
    Expanded(child: List()),  // 레이아웃 깨짐
  ],
)

// CustomScrollView + Sliver 방식 (O)
CustomScrollView(
  slivers: [
    SliverToBoxAdapter(child: Calendar()),
    SliverFillRemaining(child: List()),
  ],
)
```

### Issue 5: 한글 로케일 설정
**문제**: table_calendar가 영어로 표시됨

**해결**:
```dart
// main.dart
await initializeDateFormatting('ko_KR', null);

// TableCalendar
TableCalendar(
  locale: 'ko_KR',
  headerStyle: HeaderStyle(
    titleTextFormatter: (date, locale) {
```
