### 3️⃣ AuthWrapper 수정 (로그인 시 테마 설정)

```dart
class AuthWrapper extends StatelessWidget {
  const AuthWrapper({super.key});

  @override
  Widget build(BuildContext context) {
    return Consumer<UserProvider>(
      builder: (context, userProvider, child) {
        if (userProvider.currentUser != null) {
          // 🔥 로그인 시 역할별 테마 적용
          final themeProvider = context.read<ThemeProvider>();
          WidgetsBinding.instance.addPostFrameCallback((_) {
            themeProvider.setRole(userProvider.currentUser?.role);
          });
          
          return const HomeScreen();
        } else {
          return const LoginScreen();
        }
      },
    );
  }
}
```

### 4️⃣ 로그아웃 시 테마 초기화

```dart
// 예: 로그아웃 버튼
Future<void> _logout() async {
  await FirebaseAuth.instance.signOut();
  
  if (mounted) {
    // 🔥 테마 초기화
    context.read<ThemeProvider>().reset();
    context.read<UserProvider>().clearUser();
  }
}
```

## 🎨 사용 방법

### 1. 기본 사용 (자동 적용)

테마가 자동으로 적용되므로 **기존 코드는 그대로 사용 가능**!

```dart
// AppBar
AppBar(
  title: Text('TO 관리'),
  // 자동으로 역할별 색상 적용됨!
)

// ElevatedButton
ElevatedButton(
  onPressed: () {},
  child: Text('저장'),
  // 자동으로 역할별 색상 적용됨!
)

// Card
Card(
  child: ListTile(
    title: Text('제목'),
  ),
  // 자동으로 역할별 스타일 적용됨!
)
```

### 2. 커스텀 색상 사용

특정 위젯에만 역할 색상을 적용하고 싶을 때:

```dart
// Provider에서 색상 가져오기
final themeProvider = context.watch<ThemeProvider>();

Container(
  color: themeProvider.primaryColor,
  child: Text(
    '역할별 색상',
    style: TextStyle(color: Colors.white),
  ),
)

// 또는 RoleTheme 직접 사용
Container(
  color: RoleTheme.getPrimaryColor(user.role),
  child: Text('직접 색상'),
)
```

### 3. 역할 배지 표시

```dart
// 풀 배지
RoleBadge(
  role: user.role,
  showIcon: true,
)

// 아이콘 없는 배지
RoleBadge(
  role: user.role,
  showIcon: false,
  fontSize: 12,
)

// 작은 점
RoleDot(
  role: user.role,
  size: 8,
)
```

### 4. 그라데이션 배경

```dart
// 그라데이션 컨테이너
RoleGradientContainer(
  role: user.role,
  height: 200,
  child: Center(
    child: Text(
      '멋진 그라데이션',
      style: TextStyle(color: Colors.white),
    ),
  ),
)

// 그라데이션 AppBar
RoleAppBar(
  role: user.role,
  title: 'TO 관리',
  actions: [
    IconButton(icon: Icon(Icons.notifications), onPressed: () {}),
  ],
)
```

class StatCard extends StatelessWidget {

  final String value;

  const StatCard({
    required this.title,
    required this.value,
    required this.icon,

        child: Row(
          children: [

              padding: const EdgeInsets.all(12),

                    title,
                    style: TextStyle(
                      fontSize: 13,
                      color: Colors.grey[600],
