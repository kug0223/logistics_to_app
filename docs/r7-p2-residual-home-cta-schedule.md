## 1. P23-N — 일정 탭 자체: **구조가 달랐다**

HEAD 를 읽고 먼저 적는다. `MyScheduleScreen` 에서 `Navigator.push` 는 **한 곳뿐**
(`InviteRegionSettingsScreen` — 초대 받을 지역). 나머지 제스처는
`_enterEditMode`(가능일 편집)와 `setState`(필터 칩)다.

**근무 카드는 route 로 가지 않는다.** `ScheduleCard` 를 탭하면 같은 화면 위에
**상세 다이얼로그**(`_showDetailDialog`)가 열린다. 카드 안의 미서명 계약 줄만
`ContractSignScreen` 으로 가는데 그것은 **상태 변경 경로라 누르지 않았다**.

→ 요청서의 "카드 → 목적지 → 복귀" 는 이 화면에서 **다이얼로그 → 닫기**다.
N/A 가 아니라 **구조가 다르다**.

| 표본 | 실행 | 결과 |
|---|---|---|
| 오늘 확정 단기 | 카드 탭 → 상세 | **PSN-1** — 같은 사업장·업무가 상세에 있다(다른 근무로 튀지 않는다) |

"목적지 재조회 후 같은 달" 을 물을 대상이 없다 → **해당 없음(구조)**.

탭 내부 Navigator pop 은 **Flutter 격리 행동으로만** 판정했다.
**기기 시스템 뒤로는 P4** 에 남긴다.
