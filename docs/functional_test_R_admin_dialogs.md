### [CloseManagementDialog — 마감 관리]

**R-003** 마감 기준: 확정 인원 == 마감된 인원 → 해당 날짜 '마감완료' 상태 표시

**R-004** 미마감 날짜 탭 → AttendanceStatusDialog(해당날짜) 오픈

**R-005** AttendanceStatusDialog에서 당일명단 수정 후 복귀 → CloseManagementDialog 재로드

**R-006** 콜체인: 당일명단 변경 → 마감관리 갱신 → 부모 화면 갱신 순서 확인

**R-007** 월 변경 버튼 탭 → 해당 월 데이터 재로드

**R-008** 빈 월 (확정 인원 0) → 마감 건수 0 표시

**R-009** 휴무일 포함 장기 근무자 → 휴무일 제외한 마감률 계산 확인

**R-010** 월말/월초 경계 데이터 → 누락 없이 표시 확인

**R-011** mounted 체크 → 다이얼로그 닫힌 후 setState 호출 방지 확인

**R-019** 확정 취소 — 단건 → 확인 다이얼로그 + 사유 입력 → 취소 처리

**R-020** 확정 취소 — 일괄 → 선택된 목록 일괄 처리
